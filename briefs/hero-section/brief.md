# Landing page hero

Build the hero section at the top of the landing page for Inklane, a
shared inbox for customer support teams. It is a full-width page section
and the first thing visitors see.

Show the headline and the subheadline, then the primary and secondary
call-to-action buttons with the given labels; the primary one should carry
more visual weight. Below them, list the product's benefits. Close the
section with social proof: the number of customers, followed by the names
of well-known customers shown as text wordmarks.

The component receives the props described by the `Props` interface. It
only needs to render; the buttons do not need to do anything.
