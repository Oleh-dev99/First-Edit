# App navigation header

Build the top navigation header for Ledgerloom, a web app that finance
teams use to manage invoices and expenses. It is a full-width bar that
sits at the top of every page of the app.

Show the product name as the brand. Show the navigation links in the
given order, and make it obvious which link is the current page. Include
the primary call-to-action button with the given label; it starts the
action people take most often. Show who is signed in: the user's name and
email, next to an avatar with their initials.

The component receives the props described by the `Props` interface. The
links point to the given addresses. It only needs to render; menus,
dropdowns and the button do not need to work.
