# Project board

Build the task board for Larkspan, a planning tool for product teams. It
is a full-width section of the project page.

Show the board's columns in the given order. Each column shows its title,
the number of cards in it, and its cards. Each card shows the task title,
its tags, the assignee's name with an avatar made from their initials,
the due date, and the number of comments. Dates arrive already formatted;
show them as they are.

The component receives the props described by the `Props` interface. It
only needs to render; cards do not need to be draggable and nothing needs
to be editable.
