# Day agenda

Build the day agenda of Morrowly, a calendar app for teams. It is a
self-sized panel on the app's home screen.

Show the date at the top, with the button for adding an event, using the
given label. Then list the day's events in order. Each event shows its
start and end times, its title, its location, the names of the people
attending and its tag. Give each tag its colour so that events of the
same kind are easy to spot. Times and the date arrive already formatted;
show them as they are.

The component receives the props described by the `Props` interface. It
only needs to render; adding an event does not need to work.
