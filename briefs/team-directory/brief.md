# Team directory

Build the team directory of Ashgrove, an intranet for growing companies.
It is a full-width section of the directory page.

Show the heading with the number of members next to it, and the button
for adding a member, using the given label. Then show the people. Each
person shows their name, role, department, location and email address,
and their current status: available, busy, away or offline. Give each
status a distinct look, and make the person's name the most prominent
detail.

The component receives the props described by the `Props` interface. It
only needs to render; the button and the email addresses do not need to
work.
