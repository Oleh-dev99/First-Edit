# Account settings form

Build the profile and notification settings form for Brindlewave, a team
messaging app. It is a full-width section of the account settings page.

Start with the section title and its description. Then show two text
inputs, one for the display name and one for the email address, each with
its label, current value and help text. Add a select for the time zone
with the given options and the current choice selected. Next, list the
notification settings: each has a label, a description and a toggle that
is on or off. End the form with the save and cancel buttons, using the
given labels.

The component receives the props described by the `Props` interface. It
only needs to render; nothing needs to be saved or validated.
